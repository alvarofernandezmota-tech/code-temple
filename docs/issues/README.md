# Issues de code-temple

Esta carpeta contiene plantillas y seguimiento de issues del repositorio.

## Estructura

- `plantilla-revision-bloques.md` — Plantilla para revisar hiperfoco y desviación por bloque de trabajo
- `YYYY-MM-DD-issue.md` — Issues individuales (por fecha o número)

## Uso

1. Crear issue en GitHub con plantilla correspondiente
2. Documentar progreso en `docs/issues/`
3. Al cerrar, mover a `docs/_archivo/issues/`
