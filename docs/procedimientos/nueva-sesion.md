# Nueva sesión

Crear archivo de sesión nueva en `docs/sesiones/YYYY/MM-mes/`.

## Uso

```bash
python3 scripts/nueva_sesion.py "nombre-corto"
python3 scripts/nueva_sesion.py hoy
```

## Resultado

- Crea: `docs/sesiones/YYYY/MM-mes/YYYY-MM-DD-nombre-corto.md`
- Abre en `$EDITOR` para escribir al momento
