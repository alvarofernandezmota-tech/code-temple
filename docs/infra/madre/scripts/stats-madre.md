# stats-madre.py

**Descripción:** Genera estadísticas de Madre

**Uso:**
```bash
cd docs/infra/madre
python3 scripts/stats-madre.py
```

**Funciones:**
- Cuenta archivos por tipo (.py, .sh, .md, .yml)
- Cuenta líneas de código
- Genera reporte en `ESTADISTICAS.md`
- Calcula promedio líneas/archivo

**Salida:**
- `ESTADISTICAS.md` - Reporte de estadísticas
