# Sistema operativo de Madre

- Distribución: Arch Linux
- Arquitectura: x86-64
- Kernel: `7.1.5-arch1-2`
- Hostname: `archlinux`
- Usuario principal: `varopc`
- Entorno gráfico: KDE Plasma
- Gestor de red: NetworkManager
- Init y servicios: systemd
- Sistema de archivos raíz: ext4
- Sistema de archivos `/home`: ext4

## Montajes principales

```text
/       -> /dev/sda2
/boot   -> /dev/sda1
/home   -> /dev/sda3
swap    -> /dev/zram0
```
