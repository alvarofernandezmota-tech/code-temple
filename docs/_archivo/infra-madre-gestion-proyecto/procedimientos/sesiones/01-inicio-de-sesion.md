# Procedimiento: Inicio de Sesión de Trabajo

**Versión:** 1.0  
**Fecha:** 2026-08-13  
**Responsable:** @alvarofernandezmota-tech

## Objetivo

Documentar el procedimiento estándar para iniciar una sesión de trabajo.

## Checklist

### 1. Documentar Sesión
- [ ] Crear archivo de sesión
- [ ] Registrar hora y participantes
- [ ] Registrar objetivos

### 2. Verificar Estado del Repo
- [ ] `git status` - limpio
- [ ] `git fetch origin` - actualizado
- [ ] Alineado con origin

### 3. Revisar Issues
- [ ] Listar issues
- [ ] Identificar pendientes
- [ ] Seleccionar a trabajar

### 4. Revisar Documentación
- [ ] Ver README
- [ ] Ver procedimientos
- [ ] Ver últimos commits

### 5. Commit de Inicio
- [ ] Agregar archivo
- [ ] Commit
- [ ] Push
