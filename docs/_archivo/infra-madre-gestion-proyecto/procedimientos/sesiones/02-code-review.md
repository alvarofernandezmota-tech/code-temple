# Procedimiento: Code Review con Agente IA

**Versión:** 1.0  
**Fecha:** 2026-08-13

## Agentes Disponibles

1. **GitHub Copilot Code Review** (Nativo)
2. **CodeRabbit** (GitHub App)
3. **Greptile** (GitHub App)

## Configuración

1. Settings → Rules → Rulesets
2. New ruleset → New branch ruleset
3. Target: main
4. Automatically request Copilot code review
5. Save

## Uso

1. Crear PR
2. Copilot revisa automáticamente
3. Revisar comentarios
4. Corregir
5. Merge
