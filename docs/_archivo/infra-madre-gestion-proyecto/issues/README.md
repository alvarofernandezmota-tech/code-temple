# Issues de Infraestructura Madre

Este directorio contiene la documentación detallada de cada issue de infraestructura de Madre.

## Estructura

Cada issue tiene su propia carpeta con:
- `README.md` - Progreso actual del issue
- `commands/` - Scripts de los comandos ejecutados
- `outputs/` - Outputs de los comandos
- `audit/` - Auditorías completas
- `decisions/` - Decisiones arquitectónicas (ADRs)
