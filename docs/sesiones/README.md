# Sesiones de trabajo

Esta carpeta contiene sesiones técnicas y operativas de trabajo.

## Estructura

```text
sesiones/
└── YYYY/
    └── MM-mes/
        └── YYYY-MM-DD-descripcion.md
```

## Contenido obligatorio

Cada sesión debe registrar:

- Fecha.
- Objetivo.
- Trabajo realizado.
- Decisiones.
- Repositorios afectados.
- Commits realizados.
- Problemas encontrados.
- Pendientes.
- Próximo paso.

## Separación

Este diario registra el trabajo técnico realizado.

- El estado de Madre va en `docs/infra/madre/`.
- Los cambios permanentes van en `docs/infra/madre/cambios.md`.
- Las decisiones estructurales van en los ADR.
- Las reflexiones personales no van aquí.
