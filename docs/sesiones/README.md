# Sesiones de trabajo

Log diario de trabajo en code-temple. Un archivo por día.

**Convención (ver issue #59, en proceso de unificación):**
`YYYY/MM-mes/YYYY-MM-DD.md` — un único archivo por día, con secciones internas
si hay varios bloques de trabajo en el mismo día (usar plantilla-sesion.md).

Formatos antiguos a corregir: `SESION-YYYY-MM-DD.md`, `YYYY-MM-DD-cierre.md`,
`YYYY-MM-DD-inicio.md`, carpetas sueltas `YYYY-MM-DD-*/`.
