# Diarios personales

## Estructura

```text
diarios/
└── YYYY/
    └── MM-mes/
        └── YYYY-MM-DD-diario.md
```

## Contenido

El diario personal puede incluir:

- Cómo ha sido el día.
- Reflexiones.
- Estado personal.
- Aprendizajes.
- Hábitos.
- Experiencias importantes.

## Separación

El diario personal no contiene procedimientos técnicos ni inventarios de
infraestructura.

Las sesiones de trabajo técnico se registran en el repositorio correspondiente.
